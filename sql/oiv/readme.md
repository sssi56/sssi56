### Данный проект вычисляет сотрудников организации, указанной в so_dep.id = * 
Для работы проекта необходимо сначала запустить:
```bash
docker-compose up -d 
```
1. Скрипт для копирования таблиц:
```bash
dump_department.sh
```
2. Скрипт для создания таблицы организаций, где можно посмотреть id конкретной организации:
```bash
spisok_org.sh
```
3. Скрипты, который создают таблицы sotr_spisok_*(ФИО, логин) и result_table_* (ФИО, логин, email): 
```bash
cit.sh min_cifra.sh
```
Для перезаписи таблиц рекомендуется выполнить скрипт очистки:
```bash
drop_scheme.sh
```

Postgresql-15 же, установленный в системе, является проводником для копирования в докер-контейнер.
