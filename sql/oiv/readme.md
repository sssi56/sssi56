Данный проект вычисляет сотрудников организации, указанной в so_dep.id = * \
Для работы проекта необходимо сначала запустить:
```bash
docker-compose up -d 
```
Далее скрипы типа: 
```bash
cit.sh min_cifra.sh
```
и т.д. \
Которые выполняют копирование таблиц из БД см6 путем создания dump-файла и восстановления его в докер-контейнере. \
Постгрес же, установленный в системе, является проводником для копирования в докер-контейнер. \
